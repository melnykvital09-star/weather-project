Налаштування середовища розробки та Git workflow

## Варіант 6

Погодні спостереження

### Мета роботи

Навчитися створювати Python-проєкт, організовувати його структуру та використовувати систему контролю версій Git і платформу GitHub.

## Опис проєкту

Проєкт призначений для аналізу погодних даних.

Програма працює з температурою та опадами і дозволяє:

- знаходити середню температуру;
- визначати кількість днів з опадами;
- знаходити найвищу температуру;
- знаходити найнижчу температуру;
- визначати різницю між найвищою та найнижчою температурою.

## Структура проєкту

- 'main.py' — головний файл програми.
- 'weather.py' — модуль з функціями аналізу погодних даних.
- 'README.md' — опис проєкту.
- 'CHANGELOG.md' — історія змін проєкту.
- '.gitignore' — файли, які Git не повинен додавати до репозиторію.
- 'lab02-report.md' — звіт з лабораторної роботи.

## Використані функції

У файлі weather.py створено такі функції:

- 'average_temperature()' — обчислює середню температуру;
- 'rainy_days()' — визначає кількість днів з опадами;
- 'hottest_day()' — знаходить найвищу температуру;
- 'coldest_day()' — знаходить найнижчу температуру;
- 'temperature_range()' — визначає різницю між максимальною та мінімальною температурою.

## Висновок

Під час виконання лабораторної роботи було створено Python-проєкт «Погодні спостереження». Проєкт розділено на окремі файли та модулі. Було створено функції для аналізу температури та опадів, файл документації README.md, журнал змін CHANGELOG.md та файл .gitignore.
Наступним етапом є використання Git для контролю версій проєкту та GitHub для його зберігання.
