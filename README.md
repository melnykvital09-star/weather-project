# Погодні спостереження

Це навчальний Payton-проєкт для аналізу погодних данихю

## Можливості

Програма дозволяє:

- знаходити середню температуру;
- визначати кількість днів з опадами;
- знаходити найіищу температкру;
- знаходити найнижчу температуру;
- визначати різницю між найвищою та найнижчою температурою.

## Структура проєкту

- 'main.py' - головний файл програми.
- 'weather.py' - модуль з функціями для аналізу погоди.
- 'README.md' - опис проєкту.

## Запуск програми

Для запуску програми потрібно виконати:

'''bash
pyton main.py
